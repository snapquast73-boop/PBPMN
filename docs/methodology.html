Data & methodology

Choose a calendar date from 2014 onward. The viewer queries MLB’s schedule for sport 1 and game types R, F, D, L and W. Game details come from the selected official feed. No bundled game data is substituted on error. Every data row links to its source; an absent value stays blank (unverified).

Reading a game

Schedule timestamps in the viewer are MLB’s UTC timestamps. The separate historical schedule audit labels times in Eastern time. The overview and box score show only supplied fields. Expand a play to inspect pitch, action and runner records. Search matches the official play record, including names and descriptions.

Provenance and exports

Requests use the exact HTTPS Stats API host without redirects. The viewer checks the response status, JSON, MLB notice and requested game ID. Raw JSON is the response body. The text report and NDJSON include its source URL, retrieval time, MLB notice and SHA-256 digest. NDJSON starts with metadata, followed by plays and their events.

Live observations

Live games refresh at the feed’s wait interval (30 seconds if absent). The event log records observed official values and changes on this device, including scores, play rulings, non-pitch actions and MLB event markers. It is not a complete history: changes between polls or while the viewer was closed may be missed. Clearing browser storage removes it.
